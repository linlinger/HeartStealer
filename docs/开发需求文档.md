# HeartStealer(夺心者)开发需求文档

> 版本:v1.0 | 日期:2026-08-12 | 基础:heartstealer-template-1.21.11(Fabric 官网 1.21.11 模板)

---

## 一、项目一句话简介

一个「以战养战」的生存挑战模组:**开局只有半颗心**,通过**击杀生物**不断夺取生命上限和攻击力,越杀越强,死亡不掉落。

---

## 二、已确认的核心需求(与用户逐条确认过)

| # | 需求点 | 确认内容 |
|---|--------|----------|
| 1 | 初始状态 | 玩家开局生命上限 = **1.0(半颗心)**;攻击力保持原版默认 |
| 2 | 击杀奖励-生命 | 击杀任意生物,生命上限 **+= 该生物的最大生命值**(如击杀 5 心的兔子,生命上限 +10),并且**当前血量同时回复等量**(击杀回复;2026-08-12 补充) |
| 3 | 击杀奖励-攻击 | 击杀任意生物,攻击力加成 **+1**(可配置倍数)。加成作用于**玩家造成的所有武器伤害**:近战(剑/斧/徒手)、远程(弓/弩/三叉戟投掷)、投掷物(雪球/鸡蛋/喷溅药水);**TNT、重生锚、末地放床的爆炸不计**(2026-08-13 补充:见 §5.6)。**PvP 默认不加成**:远程/投掷物打玩家保持原版伤害,可配置 `pvpDamageBonus` 开启 |
| 4 | 死亡惩罚 | **无惩罚**:死亡重生后永久保留全部已获得的加成 |
| 5 | 生物范围 | **全部生物**均触发:被动/中立/敌对/Boss 全算;PvP 击杀其他玩家也按对方当前生命上限计算 |
| 6 | HUD 显示 | 原版装甲栏上方显示:**攻击力加成(攻击 +N)** 和 **当前最大生命(生命 N)** |
| 7 | 血条模式 | 双模式自动切换:装了 colorfulhearts(可选)交给它渲染;没装且配置开启时本模组自绘红条(含状态变色);也可配置完全关闭,只用原版 |
| 8 | 配置文件 | 开放配置文件,所有数值可调(Cloth Config + ModMenu 图形界面) |

## 四、配置项一览(写入 `config/heartstealer.json`)

### 常规(general)
| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `initialHealth` | double | 1.0 | 开局生命上限(1.0 = 半颗心) |
| `attackDamagePerKill` | double | 1.0 | 每次击杀增加的攻击力 |
| `keepOnDeath` | boolean | true | 死亡是否保留加成 |
| `includePassive` | boolean | true | 被动生物是否计入 |
| `includeHostile` | boolean | true | 敌对生物是否计入 |
| `includeBoss` | boolean | true | Boss 是否计入 |
| `includePlayers` | boolean | false | PvP 击杀是否计入奖励(默认关闭) |
| `pvpDamageBonus` | boolean | false | PvP 伤害加成(默认关闭:远程/投掷物打玩家不加加成,打怪始终加) |
| `bossMultiplier` | double | 1.0 | Boss 生命加成倍率(0.5 = 减半) |
| `entityBlacklist` | List\<String\> | `["minecraft:armor_stand"]` | 黑名单实体 ID(默认已排除盔甲架,可追加如 `minecraft:villager`) |

### HUD / 血条(hud)
| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `customHealthBar` | boolean | true | 使用本模组自绘红条+装甲栏;装了 colorfulhearts 自动交给它只显示文字;false=完全禁用自绘 |
| `healthBarMode` | enum | `DNF` | `DNF`(多层彩色)/ `NUMERIC`(数字补偿)(早期方案遗留,暂不生效) |
| `maxHealthLayers` | int | 5 | DNF 模式最多渲染多少层(1 层 = 3 排血条),超出显示 +N |
| `layerColors` | List\<String\> | 红/金/绿/蓝/紫 | 每层血条颜色 |
| `showAttackHud` | boolean | true | 是否显示攻击力 HUD |
| `hudPosition` | enum | `TOP_RIGHT` | 左上/右上/左下/右下 |

## 五、技术方案

### 5.1 属性系统
- **生命上限**:直接改 `Attributes.MAX_HEALTH` 的 **base value**,击杀时 `+= 被击杀生物 maxHealth`。base value 会被原版自动持久化到玩家 NBT,死亡/重登不丢。
- **攻击力**:用固定 UUID 的 **AttributeModifier**(Operation = ADD_VALUE),每次击杀累加 `count × attackDamagePerKill`。用 modifier 而不是改 base value,是为了**不干扰武器伤害计算**(武器是 base value 的一部分)。
- **持久化**:生命 base value 自动持久化;攻击 modifier 用 `addPermanentModifier` 也会随玩家 NBT 保存;重生时通过 `ServerPlayerEvents.COPY_FROM` 把旧实例属性完整复制到新实例(死亡无惩罚)。

### 5.2 击杀判定
- 使用 Fabric API 事件 `ServerLivingEntityEvents.AFTER_DEATH`(服务端,实体死亡后触发)。
- 判定「是玩家杀死的」:检查 `DamageSource` 归属——
  1. 直接攻击者 `source.getEntity()` 是 ServerPlayer;
  2. 或弹射物(箭/三叉戟/伤害药水)`source.getDirectEntity()` 的 `getOwner()` 是 ServerPlayer。
- 环境伤害(摔落/溺水/岩浆)不算;生物互杀不算(除非最后击杀来源归属玩家)。

### 5.3 开局半颗心
- `ServerPlayConnectionEvents.JOIN`(玩家进服)时,若当前生命上限仍为原版默认 20.0,说明是新玩家/未初始化,则设为 `initialHealth`。
- 为避免和重生逻辑打架:重生走 COPY_FROM 复制,不在 JOIN 里重复初始化。

### 5.4 客户端 HUD 与血条(两种渲染模式,运行时自动切换)
- 用 Fabric API `HudRenderCallback` 在原版装甲栏上方绘制两行文字:`攻击 +N`、`生命 N`(任何模式都画)。
- **纯文字模式**(装了 colorfulhearts 或配置 `customHealthBar=false`):不隐藏原版红心/装甲栏,血条渲染交给 colorfulhearts(可选依赖,负责美化原版红心),本模组只显示两行加成文字。
- **自定义模式**(没装 colorfulhearts 且配置开启):`GuiHeartsMixin`/`GuiArmorMixin` **条件化**隐藏原版红心与装甲栏,自绘 60×8px 红条(位置同原版红心第一排,血量文字 `当前/最大` 内嵌居中,中毒/凋零/冰冻变色)+ 原版样式装甲栏 + 两行文字。
- **检测方式**:`FabricLoader.isModLoaded("colorfulhearts")`,可靠无副作用;自绘代码完整保留,随时可启用。

### 5.5 版本兼容说明
- 目标版本 1.21.11(Mojang 映射)。代码使用官方 API 事件 + 少量 Mixin,降低跨版本破坏风险。

### 5.6 伤害加成范围(近战 / 远程 / 投掷物全生效)
- **近战**:攻击力加成通过 `Attributes.ATTACK_DAMAGE` 的属性修饰符实现(见 §5.1),进入伤害结算时原版自带,吃护甲减免。
- **远程与投掷物**:`mixin/LivingEntityHurtMixin` 用 `@Redirect` 重定向 `hurtServer` 内部对 `actuallyHurt` 的调用,判定"这次伤害是玩家拥有的弹射物(Projectile)造成的",就给传给 `actuallyHurt` 的伤害值加上攻击加成。
- **判定规则**(自然排除三种爆炸):
  1. 取 `source.getDirectEntity()`:弹射物伤害 = 弹射物本体;TNT/床/锚爆炸 = TNT 实体或空;
  2. 若直接实体是 `Projectile` 且 `getOwner()` 是玩家 → 加成(雪球/鸡蛋/药水/箭/三叉戟全部命中);
  3. TNT、重生锚、末地床爆炸**不是弹射物、也没有"玩家主人"记录 → 天然不命中,无需特殊处理**;
  4. **PvP 默认不加**(配置 `pvpDamageBonus=false`):被打目标是玩家时跳过加成,保持原版伤害;打怪始终加。
- **注入点细节(1.21.11 坑)**:`hurtServer` 签名为 `(ServerLevel, DamageSource, float)`,比旧版本多一个 `ServerLevel` 参数;`Projectile` 已移到 `net.minecraft.world.entity.projectile.Projectile`;`actuallyHurt` 在 `hurtServer` 里 if/else 互斥调用两次(无敌帧内/正常),`@Redirect` 两个调用点都接管,但运行时只执行一个分支 → 加成只加一次;护甲/魔抗减免在 `actuallyHurt` 内部,加成加到其参数上即在减免前生效,吃护甲、与近战一致。
- **攻击力上限**:原版 `ATTACK_DAMAGE` 属性上限 2048(字节码确认),`AttributeCapMixin` 已放开(只保下限),保证近战与远程长期一致增长。

## 七、验收标准

1. 进服后血条只剩半颗心。
2. 击杀任意生物:右下角/配置角显示的生命上限与攻击力增加;生命上限增加量 = 该生物最大生命。
3. 击杀 Boss(凋灵/末影龙):生命上限大幅增加,血条以 DNF 彩色分层显示,不铺满全屏,超出部分显示 +N。
4. 死亡重生后:生命上限与攻击力加成全部保留。
5. 配置文件 `config/heartstealer.json` 生成,ModMenu 可打开图形配置界面;修改 `initialHealth` 等即时生效。
6. 手持剑与空手攻击都能吃到攻击力加成;药水/火焰伤害不叠加攻击力。
7. 日志无报错、无 Mixin 注入失败崩溃。

## 附录 A:2026-08-12 实现修订记录(与 1.21.11 映射有关,重要)

实际编码/编译中发现 Minecraft 1.21.11 的官方 Mojang 映射有几处**改名**,已按实际可编译的写法修正:

| 旧写法(网上老教程常见) | 1.21.11 实际写法 |
|------------------------|------------------|
| `net.minecraft.resources.ResourceLocation` | **`net.minecraft.resources.Identifier`**(整个类改名) |
| `Mob.getMobType() == MobType.MONSTER` | **`entity.getType().getCategory() == MobCategory.MONSTER`**(`MobType` 类被移除,改用生成类别) |
| `net.minecraft.client.render.RenderTickCounter` | **`net.minecraft.client.DeltaTracker`**(客户端渲染计时器改名) |

另外:
- `ModMenuIntegration.java` 最终放在 **`src/client`**(不是 `src/main`)。因为它实现 ModMenu 接口时会引用客户端类 `Screen`,而模板的 `splitEnvironmentSourceSets()` 让 `src/main` 只编译"共用"部分 Minecraft,看不到客户端类。
- 本项目**不使用任何 Mixin**(服务端用 Fabric 事件,客户端用 HUD 叠加层),两个 mixins.json 均为空。
- 已通过 `gradlew build` 完整编译,产物 `build/libs/heartstealer-1.0.0.jar`,Cloth Config 已 jar-in-jar 内置。
