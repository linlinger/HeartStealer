# HeartStealer · 夺心者

一个「以战养战」的 Minecraft Fabric 生存挑战模组:**开局只有半颗心,击杀生物夺取生命与力量,越战越强!**

---

## 🎮 玩法

- **开局脆弱**:进游戏只有 **1 点生命 = 半颗心**。
- **击杀变强**:每击杀一个生物——
  - 生命上限 **+= 该生物的最大生命**,并且**当前血量也回复等量**(杀一只 5 心的兔子,生命上限 +10、当前血量 +10);
  - 攻击力加成 **+1**(可配置)。
- **加成作用所有武器**:近战(剑/斧/徒手)、远程(弓/弩/三叉戟投掷)、投掷物(雪球/鸡蛋/喷溅药水)的伤害都加上攻击力加成;**TNT、重生锚、末地放床的爆炸不算**(它们不是"你投出的弹射物")。
- **PvP 默认不加成**:打其他玩家保持原版伤害(远程/投掷物),可在配置里开启 `pvpDamageBonus`。打怪始终加加成。
- **死亡无惩罚**:死亡重生后,已获得的加成**永久保留**。
- **全部生物都算**:被动 / 敌对 / Boss / PvP 全触发(可配置开关与黑名单)。

## 🖥️ 界面

**加成文字(始终显示)**:原版装甲栏上方两行 `攻击 +N`、`生命 N`。

血条渲染分两种模式,运行时自动切换:

- **装「彩色心心 colorfulhearts」**(可选依赖,suggests):血条交给它渲染,本模组只显示加成文字,互不冲突。
- **没装 colorfulhearts 且配置 `customHealthBar` 开启**(默认):原版红心被隐藏,换成精致红条(位置与原版红心一致),血量文字(`当前/最大`)内嵌居中,上面是自己画的原版样式装甲栏 + 两行文字。
  - **状态变色**:中毒 → 绿,凋零 → 暗黑,冰冻 → 蓝(参考原版红心)。
- **配置 `customHealthBar` 关闭**:完全用原版渲染(红心 + 装甲栏),只显示加成文字(自绘代码保留备用)。

## ⚙️ 配置

- 游戏内:`Esc → Mods → HeartStealer → ⚙️ 配置`,可视化修改。
- 或直接编辑配置文件 `config/heartstealer.json`(首次运行自动生成)。

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `initialHealth` | `1.0` | 开局生命上限(1.0 = 半颗心) |
| `attackDamagePerKill` | `1.0` | 每次击杀增加的攻击力 |
| `keepOnDeath` | `true` | 死亡是否保留加成 |
| `maxHealthCap` | `1000000.0` | 生命上限最大值(**默认≈无上限**,已绕过原版 1024;联机以主机配置为准) |
| `includePassive` / `includeHostile` / `includeBoss` | `true` | 各类生物是否计入 |
| `includePlayers` | `false` | 是否计入玩家(PvP)**默认关闭**:PvP 击杀不带来血量加成 |
| `pvpDamageBonus` | `false` | PvP 伤害加成 **默认关闭**:远程/投掷物打玩家保持原版伤害;开启后打玩家也加加成(打怪始终加) |
| `bossMultiplier` | `1.0` | Boss 生命加成倍率 |
| `entityBlacklist` | `["minecraft:armor_stand"]` | 黑名单实体 ID,**默认已排除盔甲架**(击杀白得 20 血);可追加如 `minecraft:villager` |
| `customHealthBar` | `true` | 是否使用本模组自绘红条+装甲栏。装了 colorfulhearts 时自动交给它,本模组只显示加成文字 |

## 🧰 环境与构建

- Minecraft **1.21.11** / Fabric / **Mojang 官方映射**
- 需要 **JDK 21**、Fabric API;ModMenu 为可选(有则提供配置界面)
- **可选搭配**:彩色心心 [colorfulhearts](https://modrinth.com/mod/colorfulhearts)(负责血条渲染,装了它本模组自动只显示加成文字)
- 编译:`.\gradlew build` → 产物在 `build/libs/heartstealer-1.0.0.jar`(Cloth Config 已内置)

## 🌐 联机说明

- **单人游戏**:直接可用。
- **局域网 / 服务器**:主机(服务器)需装模组;其他玩家**装了模组能看到自定义界面,不装也能玩**(属性照常成长,只是显示原版红心)。
- **配置以主机为准**:主机的 `maxHealthCap`(生命上限)会**自动同步给客户机**,联机时所有玩家的血条数值/渲染都和主机一致,不会出现客户机被钳回 1024 的异常。

## ⚠️ 已知限制

- **生命上限不再是硬限制**:原版写死 1024 点(= 512 颗心),本模组通过 Mixin 把上限改为配置项 `maxHealthCap`(默认 1024,和原版一致),想突破就把配置调大。
- 攻击力无上限,可无限成长。
